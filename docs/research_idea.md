# 研究想法草稿（探索阶段 v0.1，2026-08-26）

> 状态：探索性草稿，未定稿。本文档记录当前讨论形成的方向性想法与待定问题，后续迭代更新。
> 相关背景：`docs/literature_map.md`（领域地图 + AI-IO/AirIO 深读笔记）

## 1. 目标陈述

- 不做：绝对位置观测（无 GNSS、无视觉绝对定位）
- 不做：神经网络/学习型方法（缺乏可解释性）
- 要做：通过各种**物理约束**榨干信息，实现纯惯导定位漂移抑制
- 载体：物流无人机（初步倾向：多旋翼平台）
- 对标：AI-IO（2026，学习型 SOTA）、AirIO（2025 RA-L，学习型）、Bryson & Sukkarieh（2004，经典模型辅助）

## 2. 核心想法：把 IMU 从"积分器"变成"被校验对象"

纯惯导漂移根源 = IMU 偏置不可观测（积分器把偏置放大成漂移）。
学习型做法 = 用数据学一个偏置模型（黑箱、需真值、泛化性差）。
本方案做法 = **用物理模型造出第二条测量通道**：

- 电机转速是从 ESC 精确已知的量 → 代入动力学方程算出"理论加速度"
- 与 IMU 读数之差 = 偏置 + 阻力 + 风 + 噪声
- 结果：**比力不再是纯粹的输入，而是伪测量**；偏置/速度/风变成可观测状态

> ⚠️ 注：核心想法中的"电机转速→理论加速度"通道已随①去掉而弃用（2026-08-26）；
> 实际方案的"第二条测量通道"由⑤气压（垂直）、⑥能量（标量）/⑦磁航向（方向）承担。

## 2.1 方案筛选准则（2026-08-26 确立，最高优先级）

> **凡需要实验标定、参数辨识的模型一律去掉**；只保留：物理恒等式（T/m=g、v=0）、
> 公开标准模型（ISA 标准大气、WMM/IGRF 地磁场）与免费信号（PX4 飞行模式）。
> 推论：无台架、无风洞、无数据反辨识，装机即用（calibration-free）。

### 定位说明（2026-08-26）

- **主干（⑤⑥⑦）**：全程可用的"绝对偏置"信号——⑤垂直、⑦方向、⑥模式；它们是巡航段维持漂移上界的主力
- **附加项（②③）**：悬停窗口的"标定触发器"——③给出悬停窗口的三轴偏置/姿态标定；②零角速度版辅助陀螺偏置收敛；激活信号靠⑥/PX4 模式

### 已去掉的候选（按准则，2026-08-26）

- **① 推进模型**：T=κ·ω²、M=κ_M·Δω² 需台架/配平标定 κ 系数 → 去掉。（影响：巡航段无"力域标量锚"，框架重心转向悬停窗口标定 + ⑥⑦⑤维持）
- **④ 风场建模**：阻力 D=k₁v+k₂v² 的 k₁/k₂ 必须辨识 → 去掉。（影响：风作为未建模扰动进入残差，留作鲁棒性讨论；能量锚/磁航向可部分吸收）

### ⑤ 气压高度约束要点（2026-08-26 讨论确认）

- **为什么必选**：INS 垂直通道动态本身不稳定（重力正反馈），无高度观测时垂直漂移无界；气压计是最廉价、标配的绝对高度源
- **实现**：h = 44330.8·(1 − (p/p₀)^0.190263)（ISA）或分段模型；气压计偏置 b_p 建模为随机游走/一阶马尔可夫，随高度观测进入滤波器
- **两个坑**：
  1. **动压误差**：机身静压孔受前进气流扰动，0.5ρv² 在 15 m/s 时约 1.4 hPa ≈ 11 m 量级——与空速/相对气流速度相关，可用推进模型/风状态联动补偿（与约束①④打通）
  2. **温漂**：MEMS 气压计温漂需标定/温度补偿模型，误差控在米级
- **附加收益**：起降/悬停段"气压高度 + 推进模型垂直力平衡"可交叉校验垂直加速度计偏置

### ⑥ 能量约束要点（v2：免标定形态，2026-08-26 更新）

- **数据源**：PX4 电压电流计（稳定可得 ✅）
- **保留用法（免标定）**：
  1. **悬停检测佐证**：PX4 飞行模式信号（主判据）+ 电流形态学特征（均值/方差/频谱——纯信号处理，无物理系数），两者融合 → 约束③激活信号
- **挂起用法（需功率模型系数，按准则暂停）**：
  - 能量锚：∫P_est(v̂)dt − ∫V·I dt = 0 长期积分观测（需 P(v) 模型系数）
  - 载荷估计：悬停功率 ∝ m^(3/2) 反估载重（需诱导功率系数）
  - 若后续接受"标称工程参数"（数据手册值，非实验标定），可重新启用
- **坑**：电流数据含电机/电调高频分量，形态学特征需与姿态/振动信号解缠；电池老化影响电流略偏（对形态学检测影响小）
- **论文定位**："能量/功率域作为导航辅助"在惯性导航文献中基本空白——**需文献查证后写入 novelty 声明**

### ⑦ 磁航向约束要点（2026-08-26 讨论确认）

- **机制**：磁力计测机体磁场矢量 m_body，由 WMM/IGRF 模型给地理磁场 m_geo（含磁偏角/磁倾角），观测 m_body = Rᵀ·m_geo（矢量观测）或退化为航向 ψ_mag（标量观测）
- **作用**：提供**绝对水平方向轴**——与⑥能量的速度模长正交组合 → 速度矢量完整（模长+方向）；yaw 通道可观 → 陀螺 yaw 偏置可观测；姿态估计不漂
- **坑**：
  1. **电机电流磁干扰**：多旋翼 10-50A 电流 → 机体磁场扰动（大坑）——PX4 有静态罗差校准（硬磁/软磁），但**飞行中电流变化导致的动态干扰**需"电流相关磁补偿"（磁场扰动与电流/转速的关联建模，与①③⑥联动）
  2. **磁偏角修正**：WMM 模型给真北-磁北偏差（中国东部约 -10°~+10°），必须修正
  3. 高纬度磁航向精度下降（中国中低纬度无碍）
- **观测形式建议**：用磁场**矢量** m_body 而非仅航向标量——矢量含倾角信息，姿态耦合更强，信息量更大

## 4. 最有价值的洞察：信息时间调度

物流无人机有天然信息节奏：起飞 → 长巡航 → 悬停装卸 → 巡航 → 降落。

- **高信息窗口**：悬停/起降（约束③激活，偏置+姿态被钉死）
- **低信息窗口**：长巡航（靠约束①②维持，吃悬停校准的老本）

"榨干信息"的正确姿势不是全程均匀施压，而是**把可观测性花在刀刃上**——悬停时充电、巡航时放电。这是 AI-IO/AirIO 完全没有的维度（它们数据中无悬停段、全程均匀学习）。

## 5. 估计架构（初版）

- **在线**：ESKF（误差状态卡尔曼滤波）
  - 状态：位置/速度/姿态/惯导偏置/气动系数/风向量
  - 约束①-④写成伪测量；约束③带激活调度器（悬停检测）
- **离线增强**（可选）：因子图平滑 / RTS 平滑器 —— 把历史高信息窗口的校准应用到全航程（"榨干"的最终形态）

## 6. 差异化叙事（一句话版）

> 不依赖任何外部传感器或学习，用推进模型+运动模式+风场构成的**物理自证约束链**，让 IMU 误差状态在物流飞行剖面全程可观测，实现室外长航时纯惯导漂移抑制——补上 AI-IO 无风假设和 AirIO 无悬停模式两个洞。

## 9. 候选扩展：三 IMU 方案（2026-08-26 讨论，**用户决定：先不加，保持六条约束**）

存档备查，若后续加入可作约束⑧：

- **核心**：三 IMU 刚体一致性——任意两 IMU 差分消掉公共项：a₁−a₂ = ω̇×d + ω×(ω×d)，从加速度计独立解出 ω/ω̇（陀螺独立校验通道，打破"陀螺偏置→姿态→加速度计偏置"串联陷阱）
- **收益**：① 刚体一致性约束（约束⑧）；② 白噪声降 √N（≈1.7x，偏置漂移因环境相关不随平均显著降）；③ 容错 2/3 投票 + 联合在线标定（与 PHM 主题衔接）
- **量级**：间距 15 cm、ω=1 rad/s → 离心项 ≈0.15 m/s²，MEMS 噪声 0.01~0.05 m/s²，信噪比 3~15 可测
- **工程要点**：三 IMU 不共线摆放、拉开 10-20 cm、同一高刚度刚体（同减震板）、标定杆臂/安装角/时间同步
- **落地形态**：虚拟 IMU 加权融合（噪声 −√3）+ 一致性残差 χ² 监控（故障检测）+ 差分角运动通道（可选）+ 状态扩展（各 IMU 偏置/标度因子）
- **文献**：Yang et al. IROS 2023 (Multi-IMU proprioceptive odometry for legged robots)；RISAF 2606.29271 (2026, 大规模 MEMS 阵列一致性门控+偏置跟踪)
